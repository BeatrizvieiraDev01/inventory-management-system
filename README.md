
# Inventory Management System

Sistema web de gestão de estoque desenvolvido com Python e Django.

> Projeto demonstrativo independente, criado para fins de estudo e portfólio profissional.

## Sobre o projeto

Aplicação para organizar produtos, equipamentos e operações de estoque em uma interface web simples e intuitiva.

O objetivo é demonstrar conhecimentos em desenvolvimento backend, modelagem de dados, autenticação e construção de interfaces.

## Tecnologias planejadas

- Python
- Django
- PostgreSQL
- Bootstrap 5
- HTML e CSS

## Funcionalidades planejadas

- Autenticação de usuários
- Cadastro e consulta de produtos
- Controle de entradas e saídas
- Histórico de movimentações
- Organização por categorias e localizações
- Painel com indicadores de estoque

## Status

Em desenvolvimento.

## Segurança e dados

Este projeto utiliza dados fictícios e não contém informações de sistemas corporativos.
